# Gears: 3-D

A 3-D view of the whole gearbox, built from the stages on the left. It is for viewing only (outlines are not manufacturing CAD and not a clearance check).

Press Build 3-D (the button replaces Calculate on this sub-tab). Until it is pressed the view says there is no assembly yet.

Controls:
- Input angle slider and Play / Pause: turn the input shaft; every gear and the planet orbits follow from the pose calculation.
- Stage buttons (shown when there is more than one stage): show or hide single stages.
- The viewer toolbar and the mouse rotate and zoom the view.

If you edit the design after building, "Inputs changed" shows: build again to refresh the view.

If the 3-D view says it lost its graphics context, reload the page.

The 3-D view does not give any safety factor or life; use Point and Duty spectrum for numbers.
