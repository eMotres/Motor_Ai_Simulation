# 齿轮：配电机

已保存电机后面的减速器：针对您给定的输出负载，电机必须提供什么，以及电机已保存的点如何对比。仅使用已保存的结果；此处不做求解。

步骤：
1. 选择电机（您有权查看的模具）及其配置。
2. 选择减速器来源：当前设计（左侧正在编辑的）或已打开的保存记录（仅当在“已保存的减速器”中打开了记录时可选）。
3. 编辑负载行（模式名称、输出扭矩、输出转速，以及对应该行的电机工作制；“自动”按模式规则：连续用额定工作制，峰值用短时工作制）。“行”按钮添加一行，垃圾桶图标删除一行。
4. 按“计算”。选择电机和配置之前该按钮不可用。

每行显示状态标签：OK、缺失（电机对该行没有可用的已保存点；显示原因，减速器一侧仍会计算）或减速器失败（不做比较）。对于 OK 的行：所需电机扭矩和转速、已保存的点、余量（已保存减去所需；负值表示已保存的点不够）、啮合、轴承和搅油损耗、传动链效率、质量和单位质量扭矩。

其他标签：“仅电动”（按电动计算，不计算反向）、“轴扭矩”或“磁场扭矩（旧）”表示已保存电机扭矩的定义方式，以及记录标志，例如打开的记录变化后的“结果已过期”。

若所需点与已保存点相差超过 2%，则不给出传动链数值。
