# 齿轮（仿真 > 齿轮）

用途：对齿轮或行星减速器做筛选计算：传动比、效率、安全系数、轴承寿命、润滑、质量、3-D 视图，以及已保存电机后面的减速器。结果是估算，不是认证。仅限工程人员。

页面分两列。

左列为设计（始终可见）：
- 已保存的减速器：见单独文档。
- 工况点：预设（验收限值和要求寿命；“人形机器人关节”预设会填入一个两级示例）、润滑剂、扭矩及其作用轴（输入或输出）、输入转速、方向（正向或反向）、温度。
- 级（从输入端起依序）：添加行星、复合行星或齿轮副；为每级设置唯一名称、齿轮（齿数、模数、齿宽、变位、螺旋角、齿厚余量）、行星数和固定件，以及可选的目录轴承。上移、下移、删除用于调整或删除一级。

右列为结果：
- 四个子页：点、载荷谱、3-D、配电机。“计算”（或“生成 3-D”）运行当前子页；前三个子页使用左侧的设计。
- “筛选估算”标签始终显示。设计在上次运行后被修改时会出现“输入已更改”：请重新计算。
- 底部的“本计算未覆盖”列出模型限制，使用任何数值前请先阅读。

常用顺序：设置工况点，定义各级，在“点”页按计算，再在“载荷谱”页得到通过或不通过的结论，然后看 3-D，最后保存。

数值上的状态标签：有效、估算（简化系数或假设输入）、不支持（模型不覆盖，永远不能通过）、失败。
