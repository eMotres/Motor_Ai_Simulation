## Source and request authority

Its three admitted search fields independently bind RPM limits and requested resolution. Origins explicitly distinguish `source_pinned_torque_measured_ct_cp_intersection` from `admitted_user_search_criteria`. These residual criteria are user-selected comparison settings, not calibrated engineering qualification tolerances. All six outer qualification/publication claims remain literal false.

The projector reads exact freshly staged YAML and checks its bytes, parsed mapping, source manifest and current runtime propeller identity. It verifies the pinned propeller implementation and projector bytes against the code actually loaded before calling the existing unchanged parser. Only `torque_measured`, non-estimated, finite usable CT/CP fits with a nonempty intersection can produce a policy. It never uses `Propeller.rpm_range`'s fallback for disjoint fits. Unsupported, estimated or invalid fits produce a null envelope while preserving metadata context; integrity mismatches refuse the read. The projector is included in the snapshot code manifest. Result storage is not an authority source for this projection.
