# 方案图：编辑

把软件模块组装成图并作为研究运行的编辑器。工程人员和管理员。

步骤：
- “Select Graph”：选择已保存的图或模板（模板带有 Template 标记）。
- Palette（调色板）：把能力方块拖到画布上。把输出连到输入；数据类型不匹配或会形成环时连线被拒绝（“Wire refused: reason”）。
- 打开一个方块可查看和修改它的参数。
- Run：按拓扑顺序运行图，报告“Study completed in ...”及各方块耗时，或“Study failed”及错误。
- Save 覆盖您已保存的图（对模板，Save 会打开 Save As）；Save As 询问图名（文件名）和标题；Delete 需要确认；New 新建空图；“Reload the graph”按钮刷新列表并重新加载所选的图，会替换未保存的画布和参数修改；请先保存。

已保存的图与模板一起放在您的工作区中。这不是电机优化器，也不会向电机或目录写入任何内容。
