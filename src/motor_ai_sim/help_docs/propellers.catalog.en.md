# Propellers: Catalogue

A read-only table "Propeller catalogue (N)" of the known propellers, loaded from the server when the tab opens. If it cannot be loaded you see a red message with the reason; an empty list says "No propellers in the catalogue."

Columns (hover a header for its meaning):
- Propeller: vendor and model as published.
- Diameter and Pitch, in inches (nominal).
- Blades.
- Data: how good the data is. "Measured torque" means thrust and torque come from a published bench table; "Power estimated" means the power is estimated; "Geometry only" means only the geometry is known.
- Max tested rpm.

There are no buttons here: you cannot edit or add a propeller in the catalogue. To work with your own propeller use the Designer sub-tab.
