# 齿轮：点

对左侧设计的一个工况点计算：即您在所选边界（输入或输出）填写的扭矩和输入转速。

按“计算”。结果显示：
- 总传动比、输入输出扭矩和转速、正向与反向（反拖）效率、输入功率和损耗、输出端回差、扭转刚度、质量、外形尺寸。
- 每级每个齿轮的齿根弯曲安全系数 S_F 和齿面安全系数 S_H，各带状态标签。
- 每个轴承（仅在选择了目录轴承时）：基本寿命 L10h、静态系数 S0 和状态。
- 每个啮合的润滑状态。

单个点不会给出通过或不通过：“点：无结论”一行说明了这一点，原因列表给出未评估的内容。要得到结论，请用“载荷谱”。

破折号表示该值无法计算；将鼠标悬停在标签或原因上可看到原因（缺少输入、不支持的情况、上游失败）。没有轴承就没有轴承寿命。“失败”的轴承记录只给出诊断寿命，不给出汇总寿命。

计算后若修改了设计，会显示“输入已更改”，旧结果保留在屏幕上，直到重新计算。输入框的错误以红色显示在输入框旁和页面上方的红色框中。
