# Winding source versus terminal linkage — saved motor audit, 2026-09-23

The `5.65267315e−9 Wb` discrepancy in run09 is a **deterministic weighting inconsistency**, not numerical quadrature noise. In `fem_solver_2d.py`, `f_coil2` uses the unit-current density `J_z = direction·n_wires/A_slot` on every conductor tag (lines 4752–4764, via `build_materials` at line 1924). Its paired source functional `A·f_coil2` therefore gives conductor tag `j` weight `n_wires A_j/A_slot`. The reported `_psi2` instead sums each tag's area-normalized P2 edge-field average with weight **one** (lines 5135–5150). These agree only when all meshed conductor areas in a slot are equal, or when their field averages happen to cancel the weight difference.

The read-only `scratchpad/torque_linkage_consistency_20260923.py` reconstructed both calculations from run04 mesh vertices, tags and P2 DOFs, run09 frozen fields, the saved 12-slot/14-pole layout and six conductors per slot. It used the exact P2 edge-mean formula for the element average and grouped 36 conductor tags into six sector slots by their saved mesh centroids. In **every** slot the largest meshed conductor area exceeds the smallest by **0.1732076211%**. Reconstructed `_psi2` differs from saved production `ψ` by at most `1.08e−19 Wb`; reconstructed `sector·stack·A·f_coil2` differs from the saved source dot products by at most `1.08e−18 Wb`. Their predicted difference reproduces every one of the twelve saved phase/frame discrepancies to at most `1.08e−18 Wb`. Direct triangle area versus saved six-point quadrature area differs by at most `5.93e−21 m²`, ruling out integration precision as the cause at this scale.

The exact per-tag identity underlying the check is, with `ā_j = Σ_{e∈j} area_e·A_edge_mean,e / A_j` and `A_slot=Σ_{j∈slot}A_j`:

`ψ_reported,p = L·N_sector/n_parallel · Σ_{j∈p} sign_j ā_j`, whereas `ψ_source,p = L·N_sector · Σ_{j∈p} sign_j (n_wires A_j/A_slot) ā_j` for the run's `n_parallel=1`. Both use the same P2 element average. The source integral is the functional in the actual nonlinear equilibrium right-hand side; the reported terminal linkage follows an equal-series-conductor convention. The mismatch can matter for circuit/energy reciprocity on meshes with more unequal conductor areas.

For run09 the terminal-linkage fixed-current coenergy secants are **0.409378919609 N·m** (±1 slip cell) and **0.408169980416 N·m** (±3 cells). The exact source-functional secants were **0.409377832001** and **0.408168882556 N·m** respectively. The terminal convention raises those estimates by **1.08761e−6** and **1.09786e−6 N·m**. This is small relative to the observed `0.00120895 N·m` slip-step sensitivity, but it is a real model inconsistency, so neither linkage formula should be silently substituted for the other.

A minimal **discrete energy-consistency** change for the present homogenized, uniform-slot-`J_z` model would define the no-eddy P2 terminal map from the already assembled unit-current source vectors, `ψ_p = L·N_sector/n_parallel · (A·f_coil2[p])`, and add a test with unequal conductor areas showing `ψ_p` equals the derivative of winding source work. This changes the interpretation of terminal linkage to the source's area-weighted conductor allocation. The source's uniform slot density is an **intentional documented convention** in `field_ops.coil_copper_areas`; its total slot ampere-turns are correct. The mismatch alone does not prove that source convention is physically wrong. `_psi2` also feeds phasor initialization, non-eddy voltage/circuit solves, per-frame output and incremental inductance, so even this small formula change needs focused current- and voltage-drive regression, including `n_parallel=1,2`. Eddy current constraints use the same area-proportional slot allocation and require a separate port review.

If the topology instead requires each drawn series conductor to carry exactly the same current, the source densities should be normalized by each conductor's own meshed area, retaining equal-conductor linkage. That coordinated change affects P1/P2 and eddy imposed-current paths; it should be undertaken only after confirming the actual series/parallel strip topology and intended terminal convention. No production formula was changed here. These are two distinct model choices, so the owner should decide which represents the machine before editing the solver.
