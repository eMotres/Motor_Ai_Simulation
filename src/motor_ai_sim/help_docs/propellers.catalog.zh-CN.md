# 螺旋桨：目录

只读表格“Propeller catalogue (N)”，列出已知的螺旋桨，打开页面时从服务器加载。无法加载时显示红色消息和原因；列表为空时显示“No propellers in the catalogue.”。

列（悬停表头可看含义）：
- Propeller：厂商和型号，按公开资料。
- Diameter 和 Pitch：英寸（标称）。
- Blades：桨叶数。
- Data：数据质量。“Measured torque”表示推力和扭矩来自公开的台架表；“Power estimated”表示功率为估算；“Geometry only”表示只有几何数据。
- Max tested rpm：最高测试转速。

此处没有按钮：不能在目录中编辑或添加螺旋桨。要处理您自己的螺旋桨，请用 Designer 子页。
