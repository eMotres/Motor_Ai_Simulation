# 方案图：查看

只读图。方块是模块（或螺旋桨 S1 额定的各步骤），连线传递数据，虚线分组是反馈回路，带停止条件和迭代上限。这里不会运行或编辑任何模型。

控件：
- 视图标签：“All modules”或“Propeller S1”。
- “Show all wires”：参数来源（电机模型、限值、环境、驱动）通常以标签形式出现在使用它们的方块上；打开后画出每条连线。
- Die、Config 和 Duty 选择器：选一台电机，即可按其已保存结果看到每个方块的状态（“done”、“running”、“error”、“stored result”）；“no run yet”表示没有已保存的结果，请到对应的仿真页运行。未选电机时不显示状态。
- 重新加载按钮：重新读取图。

悬停在方块上会点亮它的连线并淡化其余部分。点击方块可打开它的公共 API 和文档链接。标有“STUB”的方块是计划中尚未实现的。无法加载图时显示“Could not load the graph”及原因。
