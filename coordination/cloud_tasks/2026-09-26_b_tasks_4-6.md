## Задание 5 — SVPWM в модуляторе

The Controller module uses sine PWM only (modulation index m ≤ 1), which under-reads available power by
17–20 % against space-vector PWM (`src/motor_ai_sim/inverter/`, `docs/CONTROLLER_MODULE_2026-09-22.md` §10).
Add SVPWM / third-harmonic injection (linear range m ≤ 2/√3) as a selectable modulation in the Controller
settings (default unchanged = sine), used by the loss model AND by the inverter voltage source in the coupled
EM drive; the star/delta triplen behaviour must stay physically correct (delta circulates triplens). Tests for
line-voltage amplitude, device currents and losses vs sine PWM.

## Задание 6 — Thermal берёт потери из проходов каплинга

Thermal tab Solve (`GET /api/thermal/field`) refuses with `no_electromagnetic_run` when the requested point is
the coupled loop's S1/limit point (e.g. 20.4 A, coil 200.2 °C), because the coupled loop's final / S1
verification EM passes are not registered as ordinary Electromagnetic runs. Register every EM pass the coupled
loop reports as its answer (final pass, limit pass, S1 verification pass) in the same store the Thermal tab
looks up, with its exact point (I, γ, rpm, coil temperature, steps), so Thermal can use it directly. When no
matching run exists, the refusal must name the exact point to run in one line. The thermal solve must never
start an EM or coupled run itself. Tests.
